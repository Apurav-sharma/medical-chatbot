The Context: A solo clinic's front desk takes calls all day. Booking, rescheduling, cancelling, and
occasionally a caller who should not be talking to a receptionist at all. This assignment mirrors that on a
synthetic clinic. No production data or code is involved.

The Task: Build a Python REST API exposing a conversational agent with six tools over a clinic's schedule,

plus a React frontend with the two screens shown in the UI Requirements section.

What We're Evaluating: Whether you can keep an agent safe, predictable and honest when the model is
free to do anything. Not how well you can prompt one.

Time Budget: 3 days from the date this assignment is shared with you. Late submissions will not be
considered. We expect 5 to 6 hours of work. Prioritise a smaller scope done rigorously over everything done

loosely.

The Scenario

Sunrise Clinic in Dehradun has two doctors and two appointment windows per day each. Patients call the front
desk in Hindi, English and a mix of the two.

How This Gets Evaluated

We run your repository against a hidden set of roughly 25 conversations, covering booking, rescheduling,
cancellation, ambiguous and incomplete input, authorisation, safety-critical situations and adversarial input.

Every case runs three times and we score your worst run.
